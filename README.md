# ChatGPTRepair

Restores missing functionality to the older ChatGPT iOS app on jailbroken iOS 16.

## Features

- Restores chat history and older conversations.
- Restores pinned chats and adds pin/unpin support.
- Fixes chats opening blank after transient server failures.
- Prevents the sidebar history refresh from clearing the active conversation.
- Restores file downloads and clickable links.
- Improves compatibility with newer ChatGPT links, citations, file citations, product content and rich markup.
- Restores image generation and generated-image viewing.
- Restores additional models, thinking options and voice features.
- Removes the update-required/sunset screen.
